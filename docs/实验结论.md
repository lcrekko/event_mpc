# Milestone B–F 实际完成情况与结论

| 阶段 | 已完成的内容 |
|---|---|
| B | 两个神经元及互抑制突触；独立振荡周期与数值收敛验证 |
| C | 精确力矩、神经元阈值脉冲、探测器事件及因果反馈重建 |
| D | 事件到事件预测、完整状态延续、幅值/机械功积分及失败状态 |

全部 28 个测试通过。独立 SciPy 参考积分器与编译后端的比较、缩小步长后的
收敛检查以及冻结候选复核均通过。B/C 的原始数组和 D 的预测结果重新生成后
与归档数据完全一致；相同种子的 200 区间实验前 50 次动作，也与独立的
50 区间实验相同。

## 实验发现

三组名义 MPC 实验的过零时间 RMS 误差平均约 **1.686 ms**，半摆极值 RMS
误差平均约 **0.264°**。固定名义 HCO 的对应误差约 **0.000506 ms** 和
**0.000132°**。本实验按论文提供的已建立振荡状态初始化，因此固定名义参数
本身已非常接近目标；这些结果没有显示 MPC 的跟踪优势。三个随机种子间也有
明显差异，不能将其中一次较好结果作为普遍结论。

名义 MPC 的绝对机械功平均约 **4.497 μJ**，固定参数为 **4.697 μJ**。
这项指标是机械功交换量，不能称作电能消耗；应与跟踪误差一起评价。
较短预测区间的机械功更低，同时幅值跟踪明显变差，也不能仅凭低机械功认定
控制性能更好。

全部 13 组闭环都完成了要求的区间数量，没有触发最终全无效候选回退。随机
射击实验中有少量候选被约束检查拒绝，它们的状态仍保存在数据中。200 区间
长运行完成，阻尼与力矩系数失配、采样预算和预测区间敏感性也已实际运行。

## 当前限制

在这台四核云端机器上，论文规模 M=256、R=2 的优化通常需要约 **1.2 秒/次**，
明显超过 **50 ms** 的名义事件间隔。仿真已经遵守第二个探测器事件之后才更新
参数的因果顺序，但优化计算耗时仅测量、未加入模拟控制延迟。因此目前不能
声称可以在真实装置上实时执行。

论文式 (2) 保留精确 `sin(alpha)` 力矩，式 (4) 和 PDF 均未修改。式 (4)
的有限角度能量残差单独记录。数值积分误差和模型原式差异没有混合隐藏。
冻结名义实验中全部 50 次单步预测，过零时间最大误差约 17ns，极值误差约
1.82e-6rad；当前观测到的控制误差远大于这两个数值误差。

Windows 的安装及 VS Code 命令已提供；实际执行与验证仍是在 Linux 云环境
完成。研究结论应继续依据报告中的具体工况，不能据此推广为稳定性或鲁棒性保证。
